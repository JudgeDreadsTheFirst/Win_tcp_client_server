# My basic WINDOWS TCP/IP Server/Client programm.
---
## Компиляция проекта 
Необходимо скомпилировать `.cpp` файлы с флагом `-с`(то есть без линковки).
### Пример
```
  g++ -c file_name.cpp
```
Следующий шаг будет получение исполняемого файла важно не забыть применять флаг `-lws2_32`.
```
  g++ file1.o file2.o -o progname.exe -lws2_32
```
В дальнейшем сюда будет добавлен MAKEfile.
## Состав проекта
`TCP_client.cpp` - реализация простого клиента для обмена сообщениями с сервером.
`TCP_server.cpp` - реализация сервера.
`common.cpp/common.h` - в этих файлах расположены функции проверки работы функций из билблиотек `winsock2.h` и `ws2tcpip.h`.
